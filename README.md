# WooUpload

Panel SaaS para gestionar y publicar productos en WooCommerce.

## Características

- Dashboard con tarjetas de estadísticas (Productos, Pendientes, Subidos, Errores)
- Gestión de productos con estados: Activo, Pendiente, Error, No publicado
- Importación desde Excel (CSV)
- Sincronización con WooCommerce
- Autenticación: email/contraseña y Google
- Recuperación de contraseña
- Perfil de usuario con avatar, nombre y cambio de contraseña
- Diseño responsive: menú lateral en escritorio, menú hamburguesa y navegación inferior en móvil

## Stack

- React + TypeScript + Vite
- Supabase (auth + base de datos)
- react-router-dom
- lucide-react (iconos)

## Scripts

- `npm run dev` — servidor de desarrollo
- `npm run build` — build de producción
- `npm run preview` — previsualizar build
